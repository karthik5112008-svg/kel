# images/

This folder is reserved for any custom product images or logos you want to use locally.

## How to add images
1. Place your `.jpg`, `.png`, or `.webp` files here.
2. Reference them in `script.js` using a relative path like `images/your-file.jpg`.

## Current Setup
All product images are loaded from **Unsplash CDN** (free, high-quality) — no download needed.
The app works fully online without any files in this folder.

## Custom Branding
You can place your store logo here:
- `images/logo.png` — Then update the brand badge in `index.html`
- `images/hero-bg.jpg` — Then update the `.hero` background-image in `style.css`
